# foodchoice

foodchoice est un projet d'application mobile pensée pour aider les utilisateurs à trouver rapidement où manger dehors, partout dans le monde, selon leur position, leur budget, leurs envies et leurs contraintes alimentaires.

## Vision

L'application doit permettre de choisir un restaurant sans perdre de temps, que l'utilisateur soit seul, entre amis, en date ou en famille. Elle combine géolocalisation, recherche par adresse, filtres alimentaires et recommandations issues de données restaurant en temps réel.

## Plateformes visées

- iOS via l'Apple App Store
- Android via le Google Play Store
